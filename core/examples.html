String Validation

Here are some string validations using regular expressions to find extraneous spacing and invisible characters. It's written in Swift but I use it in Python too. There is an all-in-one 'trimmed' method, followed by more specific methods which are helpful for providing specific feedback for user input. Alternatively, I might auto-trim user input instead of providing hints for corrections. I prefer correction hints over auto-correcting for the data entry team to help them become more aware of what they're typing or copying and pasting.
